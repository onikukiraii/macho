# ノーススターストーリー

筋トレの記録は KINNIK で行い、プログラムの管理は xlsx で行うという二重管理、別アプリでの管理をやめて一本化したいという願いがもとになっている。

私が筋トレを行うためにアプリを開くと、今日やるべき種目と重量とその回数がもうすでに入力せずとも出ている。1セット終了後にはアプリ内のタイマーを利用して3分計り、3分が経ったらアラームが鳴り、私は慌てて次のセットに取り組む。

プログラム外のトレーニング種目も追加できる。トレーニング種目は自分で自由に追加することができる。

max 重量などを換算して自動で次回の重量などの設定が置き換わり、私は日々のトレーニングを記録しているだけで勝手に筋肉を成長させることができる。

週末や月末になると筋トレ結果を CSV 出力して Claude に渡し、この重量のままでいいのかなどのパーソナルなアドバイスを得られる。

半年後、私はこの半年間の筋トレの成果を数値で確認したい気分になり、分析ページを開く。分析ページを開くと各種目の max 重量や総ボリュームなどが数値で確認することができる。

## 背景

- 記録は KINNIK、プログラムは Claude で作った xlsx で管理している
- ジムではまず xlsx を開いて今日の種目と重量を確認し、そのあと KINNIK に回数などを入力している
- 定期的に KINNIK の CSV を Claude に渡し、xlsx の更新と重量を上げるかの相談をしている
